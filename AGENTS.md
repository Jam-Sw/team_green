# AGENTS.md — repo guide for AI agents

This repo is cooperative work for **team_green** at the UREC Sustainability Design Hackathon
(**Sat Sept 26, 2026, UVic**) — a real-world **solar challenge by Solve Energy**.

## Start here

Read `skills/team-green-context/SKILL.md` for event, partner, repo layout, and conventions.
Then load what the task needs:

- `skills/bc-solar-economics/` — BC Hydro rates, rebates, savings/payback math
- `skills/solar-sizing/` — PV / PV+battery sizing method and defaults
- `skills/hackathon-deliverables/` — design package + pitch structure, time-boxing

## Conventions

- Branch → PR into `main`; small focused commits.
- Org-wide: issues and PRs follow the **OpenSpec format** (Why / What Changes / RFC 2119
  Requirements / GIVEN-WHEN-THEN Scenario / Verification checklist) — see `Jam-Sw/.github`.
- Cite sources for factual claims; label assumptions in every numeric deliverable.
