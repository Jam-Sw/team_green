# Deliverables — one-day design hackathon

## Expected package (preliminary design level)

1. Problem restatement + solution concept (one slide)
2. System block diagram / single-line (source → conversion → storage → loads/grid)
3. Sizing table (load → array → inverter → battery) with assumptions labeled
4. Site layout sketch (roof/ground, orientation, tilt, shading notes)
5. BOM with vendors + cost estimate (±30%) + rebate/incentive plan
6. Savings & payback summary (use `bc-solar-economics` formulas)
7. Risks, assumptions, and what we would validate next (engineering honesty scores points)
8. A 5-minute pitch with numbers on every slide

## What judges reward (March 2026 precedent + Solve Energy's profile)

- **Technical credibility** — right-sized numbers, real data, correct units
- **Cost realism** — installed cost, rebates, permitting/installability (Solve's daily world)
- **Deployability framing** — modularity, siting flexibility, "grid connections are expensive
  and slow to permit" style value propositions
- **Communication** — clear narrative; answer questions with numbers

## Time-box template (8:30 AM – 6:30 PM; adjust after kickoff)

- 08:30 check-in / team formation
- 09:00 challenge reveal → 09:45 restate the problem, list constraints, define "what winning means"
- 09:45 diverge: 2–3 concepts with quick feasibility screens (~30 min each max)
- 11:00 converge: pick one, sketch block diagram + site layout
- 11:30 sizing sprint: load → array → inverter → battery (spreadsheet, PVWatts running)
- 13:30 BOM + cost + rebates; payback
- 15:00 build slides; rehearse the 5-minute story; re-check units and assumptions
- 16:30 mentor/judge feedback round (if scheduled); iterate
- 17:30 final pitch

## Assets to bring

- Laptops + power, calculators; PVWatts/SAM/pvlib pre-downloaded + Victoria weather file
- Spreadsheet templates (energy balance, BOM, cost, payback); draw.io for diagrams
- This repo (research + skills) available offline
